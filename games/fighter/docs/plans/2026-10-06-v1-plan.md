# Jev Fighter (then called Stickfight) v1: implementation plan

Spec: `docs/specs/2026-10-06-stickfight-design.md`. Each milestone ends with `npm test` and
`npm run typecheck` green and a commit.

1. **Scaffold.** package.json (vite, vitest, typescript, tsx), tsconfig, `.env.example`, `.gitignore`.
2. **Engine** (`shared/engine/`): fixed-point units, moves table, fighter state machine, collisions,
   hit-stop, rounds, PRNG, events, state hash. Tests for frame data and every interaction loop.
3. **Questions** (`shared/question.ts`): legal moves, per-option facts, context, history; render to
   System One payload and to chat text.
4. **Adapters** (`adapters/`): systemone, chat (json_schema), greedy fallback. Mocked-fetch tests.
5. **Match driver** (`shared/match.ts`): ask-early prediction, invalidation, deadlines, realtime and
   paused clocks, decision log. Tests with fake adapters and a fake clock.
6. **Replay + stats** (`shared/replay.ts`, `shared/stats.ts`, `shared/elo.ts`): codec, re-simulation
   with checkpoint hashes, outcomes, calibration, Elo. Golden replay test.
7. **Bench CLI** (`scripts/bench.ts`, `scripts/smoke.ts`): real matches with `OPPER_API_KEY`,
   replays to `data/replays/`, stats table, leaderboard JSON.
8. **Server** (`server/`): `/api/decide`, `/api/warm`, `/api/replays`, `/api/leaderboard`,
   Login with Opper (`/auth/*`, `/api/me`), dev key on localhost only. Vite plugin for dev.
9. **Renderer** (`src/render/`): skeleton + keyframed poses, spring follow-through, foot planting,
   hit-stop, shake, ink splashes, trails, cracks, ragdoll KO, paper style, HUD.
10. **App** (`src/`): match setup, live match, replay viewer (scrubber, decision cards, thought
    bubbles, stats tab), gallery, leaderboard. Checked in a browser at desktop and 390 px.
