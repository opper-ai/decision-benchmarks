# Submissions

Models their makers benchmarked themselves on Pac-Man (jevman). Each folder is one model: `submission.json` and the
recorded games, written by `npm run bench -- --game pacman --endpoint … --submit games/pacman/submissions/<id> …`.
See [CONTRIBUTING.md](../../../CONTRIBUTING.md#benchmark-your-own-model).

`npm run submissions -- --game pacman` replays every game on the kit. Pac-Man is the kit's test fixture: its live
leaderboard is at [opper.ai/jevman-benchmark](https://opper.ai/jevman-benchmark/leaderboard), from
opper-ai/jevman-benchmark.
